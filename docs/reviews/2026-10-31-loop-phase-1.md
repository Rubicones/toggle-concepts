## 3. Self-Review & Risk Audit

1. **Frozen digests.** `config_hash`, `requestId` and `quoteId` do not include prompt text or catalog facts. Admitted requests replay their stored snapshots. New prompt text applies only to new requests. Image request keys (`resourceRequest`) are unchanged; the provider-side reference suffix is not part of the key.
2. **Size limits.** The first rewrite (6,908 characters) made the 128-variant director request drop every reference image and shortened handoff evidence (caught by `director-static-admission` and `director-creative-handoff`). The final director prompt is shorter than before; that request now measures 31,680 of the 32,768-byte target with one reference image kept (was about 32,300 before). The coder prompt grew from 5,446 to 7,008 characters; the 128-variant coder admission test passes. Provider schemas are unchanged.
3. **`AGENTS.md` principles.** Facts are measurements only; no code places copy or chooses a technique. No templates, zones or presets were added; the house style was removed. No paid calls, renders or screenshot sweeps were added.
4. **Other risks.** Saliency on busy photos with baked graphics is approximate (it can pick the graphic, not the face); prompts make the director's planned subject position primary. The live sandbox build test (`tests/director-live-preview` sandbox case) needs macOS and could not run here; the generated `resources.ts` type change is additive.

## 3a. Revision after owner feedback (same day)

The owner noted that the first version copied concrete 1win layout techniques into general rules and limited the agents. Legibility is now a goal with quality criteria (every word fully visible and easy to read at the real ad size in every format and locale; copy does not fight the subject or other copy), and techniques are an open, non-exhaustive repertoire the agents choose from or extend: split screens, colour fields, clean areas planned into the picture, plates, gradients, darkened or blurred zones, shaped masks, multi-image collages, type as the main visual, scale and weight. Removed fixed limits: "headline at most 2 lines", "only display text on pictures", fixed scrim opacities, "2–3 masses", "frame reserve 60–70 % so all formats crop from one still". Kept technical floors only: no clipped glyphs, language-aware wrapping, unbroken brand names/units, format `minTextPx`. Final sizes: director 4,089 characters (adds the owner's square-master recommendation: subject centred, away from the edges, at most ~50–60 % of the frame; extend a format later if needed), coder 6,485 characters.
