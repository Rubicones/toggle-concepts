- **Removed**, because the app already checks it: 2 lines.
- **Rewritten as what to do**, with the reason where it helps: 57 lines.
- **Kept as a plain rule**, because it is a real limit: 3 lines. These cover untrusted source material, credentials, approved words and facts, and using supplied marks exactly as supplied.

Every text got shorter. Nothing changes for runs already started. **The new texts are switched off until you approve them.**
