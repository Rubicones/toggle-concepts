# Forma: как всё подключить — по шагам

Две части: **А.** Forma на вашем компьютере. **Б.** Новый чат с Claude, который работает над кодом Forma.

---

## А. Forma на компьютере

Всё делает один файл — **Install-Forma.cmd**. Он же обновляет Forma; запускать можно сколько угодно раз.

### Что он настроит сам
- **Старая студия Toggle** переедет из `C:\toggle` в `C:\toggle\old-toggle-studio`. Ничего не удаляется, значок «Toggle Studio» продолжит работать.
- **Подпись запусков:** «Roman».
- **Claude:** только ваша подписка. Ключи Димы для Claude и Codex из настроек убираются; режим Codex не используется.
- **Картинки и видео:** ключ OpenRouter из файла остаётся. Установщик покажет его последние 4 символа — проверьте, что это ваш ключ.
- **Общая база и файлы с Димой** (Supabase и R2) остаются.
- **Код** берётся из вашей рабочей ветки **roman/work**, не из main. Пока чат её не создал, временно берётся main.
- На рабочем столе появится значок **«Forma Studio»**.

### Шаги
1. Закройте окно старой студии Toggle, если оно открыто.
2. Положите в `C:\toggle` файл **Install-Forma.cmd** из этого чата. Файл настроек от Димы (`doc_...env`) положите туда же или оставьте в «Загрузках».
3. Дважды кликните **`C:\toggle\Install-Forma.cmd`**.
4. Проверьте строку «Настройки: … Автор: Roman. Claude: ваша подписка. Картинки: ключ OpenRouter …XXXX». Если последние 4 символа не от вашего ключа — напишите в чат.
5. На шаге «Вход в Claude по подписке» нажмите **Enter**. В браузере выберите свой аккаунт Claude и разрешите доступ. Если в окне вместо этого показан код: скопируйте его, вставьте в окно правой кнопкой мыши и нажмите Enter.
6. Дождитесь зелёной строки **«Готово»**.
7. Запуск — значок **«Forma Studio»**. Пока работаете, окно не закрывайте. Браузер откроется сам: http://127.0.0.1:4317.
8. В форме сборки выбирайте Claude **по подписке**.

Если Windows попросит перезагрузку (только если Ubuntu не был установлен), после входа установка продолжится сама.

### Повседневное
| Что | Как |
|---|---|
| Запустить | значок «Forma Studio» |
| Забрать новые правки из чата | закройте окно Forma → двойной клик `C:\toggle\Update-Forma.cmd` → запустите снова |
| Новый файл настроек от Димы | положите в `C:\toggle` или «Загрузки» → `Update-Forma.cmd` |
| Открыть папку с кодом | `C:\toggle\Open-Forma-Folder.cmd` |
| Старая студия Toggle | `C:\toggle\old-toggle-studio\Start-Studio.cmd` или прежний значок |

## Б. Новый чат для работы над Forma

### 1. Доступ (один раз)
Сейчас Claude всё ещё не может работать с **Rubicones/forma** от вашего имени: нет прав на запись. Проверьте по порядку:
1. **Приглашение от Димы принято.** На почту GitHub приходит письмо «Rubicones invited you to collaborate on forma». Нажмите в нём **Accept invitation** или откройте https://github.com/Rubicones/forma/invitations.
2. **Приложение Claude подключено к forma.** Дима: https://github.com/apps/claude/installations/select_target → Rubicones → Configure → в «Repository access» должен быть **forma** → Save.
3. **Переподключите GitHub в Claude:** https://claude.ai/connect-github.

### 2. Начать чат
1. claude.ai/code → новая сессия → в выборе репозитория отметьте **Rubicones/forma**. Если его нет в списке, значит не сделан один из трёх пунктов выше.
2. Первым сообщением вставьте текст из **new-chat-prompt.md** и приложите файл **2026-11-16-quality-findings.md**.
3. Допишите в конце сообщения задачу.

Ключи и файл настроек в чат не отправляйте: чат работает с кодом, а запускаете Forma вы у себя.

### 3. Как проверять работу чата
Чат правит ветку **roman/work** и пушит её. Вы закрываете окно Forma, кликаете `Update-Forma.cmd`, запускаете Forma и смотрите результат.
