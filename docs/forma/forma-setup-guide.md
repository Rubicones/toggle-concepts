# Forma: как всё подключить

Две части: **(1)** Forma у вас на компьютере, **(2)** новый чат с Claude, который работает над кодом Forma.

---

## 1. Forma на компьютере

Всё делает один файл — **Install-Forma.cmd**. Он же обновляет Forma, его можно запускать сколько угодно раз.

### Что он делает
- Переносит файлы прежней студии Toggle из `C:\toggle` в `C:\toggle\old-toggle-studio`. Ничего не удаляет. Старая студия остаётся рабочей: её значок «Toggle Studio» на рабочем столе перенаправляется на новое место.
- Использует тот же Ubuntu (WSL), что и Toggle. Включает в нём «зеркальный» режим сети, чтобы браузер Windows открывал Forma.
- Находит файл настроек от Димы (в `C:\toggle` или в «Загрузках», под любым именем) и копирует его в `C:\toggle\forma.env`.
- Один раз спрашивает ваше имя: им подписываются ваши запуски в общей базе. В файле от Димы стоит его имя.
- Скачивает код Forma, ставит зависимости и Codex, предлагает войти в Claude по подписке.
- Создаёт `Start-Forma.cmd`, `Update-Forma.cmd`, `Open-Forma-Folder.cmd` и значок **«Forma Studio»** на рабочем столе.

### Шаги
1. Закройте окно прежней студии Toggle, если оно открыто.
2. Положите в `C:\toggle` два файла:
   - `Install-Forma.cmd` (из этого чата);
   - файл настроек от Димы (`doc_...env`). Можно оставить его в «Загрузках».
3. Дважды кликните **`C:\toggle\Install-Forma.cmd`**.
4. На вопрос «Ваше имя» напишите своё имя и нажмите Enter.
5. На шаге «Вход в Claude по подписке» нажмите Enter. Откроется браузер: выберите свой аккаунт Claude и разрешите доступ. Если вместо этого в окне показан код, скопируйте его, вставьте в окно правой кнопкой мыши и нажмите Enter.
6. Дождитесь зелёной строки «Готово».
7. Запуск: значок **«Forma Studio»** на рабочем столе. Окно не закрывайте, пока работаете; браузер откроется сам на http://127.0.0.1:4317.

Если Windows попросит перезагрузку (так бывает, только если Ubuntu не был установлен), после входа установка продолжится сама.

### Важно про ключи в файле от Димы
- В файле — ключи Димы: Anthropic, Codex, OpenRouter, а также доступ к общей базе Supabase и файлам R2.
- **Генерации оплачивает тот, чей ключ в файле.** Чтобы платить за Claude своей подпиской, в форме сборки выбирайте вход по подписке. Чтобы картинки и видео шли с вашего счёта OpenRouter, замените `OPENROUTER_API_KEY` в `C:\toggle\forma.env` на свой и дважды кликните `Update-Forma.cmd`.
- Файл никуда не пересылайте и не коммитьте.

### Повседневное
| Что | Как |
|---|---|
| Запустить | значок «Forma Studio» |
| Обновить код | двойной клик `C:\toggle\Update-Forma.cmd` (сначала закройте окно Forma) |
| Проверить ветку из чата | впишите имя ветки одной строкой в `C:\toggle\forma-branch.txt`, затем `Update-Forma.cmd`. Удалите файл — вернётесь на main |
| Новый файл настроек | положите его в `C:\toggle` или «Загрузки», затем `Update-Forma.cmd` |
| Открыть папку с кодом | `C:\toggle\Open-Forma-Folder.cmd` |
| Старая студия Toggle | `C:\toggle\old-toggle-studio\Start-Studio.cmd` или прежний значок |

## 2. Новый чат для работы над Forma

### Один раз: доступ Claude к репозиторию
Сейчас Claude не видит репозиторий **Rubicones/forma**: приложение Claude на GitHub к нему не подключено.
1. Попросите Диму (владельца Rubicones) открыть https://github.com/apps/claude/installations/select_target → выбрать **Rubicones** → **Configure** → в «Repository access» добавить **forma** → **Save**.
2. Убедитесь, что у вас есть права на запись в репозиторий forma (Дима добавляет вас как collaborator).
3. Если GitHub отвязался: https://claude.ai/connect-github.

### Начать чат
1. Откройте claude.ai/code → новая сессия → в выборе репозитория отметьте **Rubicones/forma**.
2. Первым сообщением вставьте текст из файла **new-chat-prompt.md** и приложите файл **2026-11-16-quality-findings.md**. В конце напишите задачу.
3. Ключи в чат не нужны: чат работает с кодом и тестами, а запускаете Forma вы у себя. Файл настроек в чат не отправляйте.

### Как проверять работу чата
Чат работает в своей ветке и называет её. Вы вписываете имя ветки в `C:\toggle\forma-branch.txt`, кликаете `Update-Forma.cmd`, запускаете Forma и смотрите. Как с Toggle.
