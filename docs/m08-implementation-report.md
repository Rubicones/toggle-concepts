## P0 — Remotion toolchain

Added app-owned direction input/brand/copy types, per-direction workspaces, paused GSAP timelines (including SplitText, MorphSVG, DrawSVG, MotionPath, CustomEase and Flip), Three.js support with `--gl=angle`, Node-callable typecheck/bundle/still/MP4/check tools, AST determinism lint, DOM geometry capture and pixel checks. Checks report failures without changing the composition. The hand-written Sonicdesk fixture adapts to four formats, with montage camera motion, kinetic hook, UI comment macro, a rotating Three.js torus, and lime CTA press.

Sandbox: mandatory macOS `sandbox-exec`, no external IP networking, local renderer/resources only, CSP confines resource requests to the local renderer origin, writes restricted to the direction folder and a private runtime directory within it. Agent source is bundled/typechecked as data, never imported into the worker. Renderer subprocess groups have a 180 second deadline, 4 GiB aggregate RSS ceiling, 1 GiB Node heap, 30 second Remotion render timeout, 80 source files, 512 KiB per source and bounded tool output. Other platforms fail closed until equivalent isolation exists. Fonts and media are served locally. Headless Shell is installed separately (`ensureBrowser`) before running the isolated worker. Static lint is defense in depth, not the OS security boundary.

Verification: typecheck PASS; lint PASS; npm test PASS (281 tests); next build PASS. Final fixture: 33 sampled frames per format, foreground/background pixel checks and each frame re-rendered in reverse order. Vertical 1080×1920: PASS, 56,040 ms. Square 1080×1080: PASS, 55,128 ms. Portrait 1080×1350: PASS, 53,016 ms. Wide 1920×1080: PASS, 53,278 ms. Timings include full MP4 rendering and frame checks, with two independent formats rendered concurrently. Machine-readable results: `docs/m08/p0-render-results.json`; command results: `docs/m08/P0-verification.json`. Dmitry performs the visual review.

## Practical limits and handoff

- Dmitry must apply migrations 040–044 before starting director work, configure the desired strong coding/vision models, and perform visual review. Paid provider submission, receipts and role/run guards are implemented, but live-provider and applied-database end-to-end behavior was deliberately not exercised.
- DOM/SVG and solid-colour Canvas2D text have measured geometry and pixel evidence. Text baked only into supplied/generated bitmaps, WebGL textures, or gradient/pattern Canvas glyphs cannot be certified semantically by this instrumentation; OCR/general glyph segmentation is not implemented. All objective checks sample rendered frames rather than proving every pixel at every time. Natural-language brand instructions remain director/critic inputs; numeric font, colour, contrast, safe-zone and clear-space rules are checked directly.
- Global synthesis permission is accepted automatically only for an unambiguous positive still-generation statement. Other permission wording produces an exact-resource consent question. Brand font substitution requires an already approved fallback; no implicit font substitution is made.
- Ordered variants use the five requested props. Legacy rows with identical five-prop values but conflicting approved copy are rejected for clarification. Unrendered variants remain available on demand and are checked when rendered. Delivery uses the existing delivery descriptor and the director review workspace; historical batch/layer-edit screens do not generate new director output.
- The sandbox is macOS-only and requires the installed Headless Shell; other platforms fail closed. Archived versions refuse rendering after a toolchain version change until the matching toolchain is available. Local `artifacts/m08` contains MP4s, source workspaces and full check logs; compact verification records are committed under `docs/m08`.
