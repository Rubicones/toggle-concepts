## Principles
Before you write or build, state the frame's idea in one sentence a viewer could repeat. If you need two sentences, you have two frames, or one idea too many. Every element either makes that sentence clearer or is removed. A second message weakens the first more than it adds.

## Checks
- [ideas] Can each idea be said in one sentence a viewer could repeat?
- [ideas] Does each idea carry a single message?
- Does every element in the frame serve the frame's one idea?

## Signs for the reviewer
The frame or the idea needs two sentences to explain.
A second message competes with the first.
